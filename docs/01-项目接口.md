# 项目接口文档

## 1. 用户相关接口

### 1.1 用户微信登录

**功能描述**：用户通过微信登录或注册系统

**请求URL**：`/api/user/login`

**请求方法**：POST

**请求参数**：
| 参数名 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| openId | string | 否 | 微信OpenID |
| unionId | string | 否 | 微信UnionID |
| nickName | string | 否 | 用户昵称 |
| avatarUrl | string | 否 | 用户头像URL |
| phoneNumber | string | 否 | 用户手机号 |
| channel | string | 否 | 来源渠道 |

**响应参数**：
| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| code | number | 响应状态码，0表示成功，-1表示失败 |
| msg | string | 响应消息 |
| data | object | 响应数据 |
| data.token | string | 用户登录令牌 |
| data.userInfo | object | 用户信息 |
| data.userInfo.id | number | 用户ID |
| data.userInfo.phone | string | 用户手机号 |
| data.userInfo.img | string | 用户头像 |
| data.userInfo.nickName | string | 用户昵称 |
| data.userInfo.openId | string | 微信OpenID |

**响应示例**：
```json
{
  "code": 0,
  "msg": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userInfo": {
      "id": 1,
      "phone": "13800138000",
      "img": "https://example.com/avatar.jpg",
      "nickName": "用户123456",
      "openId": "wx_1234567890"
    }
  }
}
```

### 1.2 生成二维码

**功能描述**：生成包含分享链接的二维码图片

**请求URL**：`/api/user/qrcode`

**请求方法**：GET

**请求参数**：
| 参数名 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| channel | string | 否 | 景区channel，默认值为1001 |

**响应参数**：
- 响应类型：`image/png`
- 响应内容：二维码图片

### 1.3 分享链接

**功能描述**：处理分享链接，返回景区信息

**请求URL**：`/api/user/share/:channel`

**请求方法**：GET

**路径参数**：
| 参数名 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| channel | string | 是 | 景区channel |

**响应参数**：
| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| code | number | 响应状态码，0表示成功，-1表示失败 |
| msg | string | 响应消息 |
| data | object | 响应数据 |
| data.channel | string | 景区channel |
| data.message | string | 欢迎消息 |

**响应示例**：
```json
{
  "code": 0,
  "msg": "访问成功",
  "data": {
    "channel": "1001",
    "message": "欢迎访问景区 1001 的分享页面"
  }
}
```

## 2. 订单相关接口

### 2.1 支付押金

**功能描述**：用户支付押金，创建押金订单

**请求URL**：`/api/user/pay`

**请求方法**：POST

**请求头**：
| 参数名 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| Authorization | string | 是 | 用户登录令牌 |

**请求参数**：
| 参数名 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| items | array | 是 | 物品列表 |
| items[].giftId | number | 是 | 礼品ID |
| items[].quantity | number | 是 | 数量 |
| items[].price | number | 是 | 价格 |

**响应参数**：
| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| code | number | 响应状态码，0表示成功，-1表示失败 |
| msg | string | 响应消息 |
| data | object | 响应数据 |
| data.orderNo | string | 订单编号 |
| data.orderPrice | number | 订单价格 |
| data.orderNum | number | 订单数量 |

**响应示例**：
```json
{
  "code": 0,
  "msg": "订单创建成功",
  "data": {
    "orderNo": "ORD2026031600001",
    "orderPrice": 100.00,
    "orderNum": 2
  }
}
```

| 参数名 | 类型 | 描述 |
| --- | --- | --- |
| code | number | 响应状态码，0表示成功，-1表示失败 |
| msg | string | 响应消息 |
| data | object | 响应数据 |
| data.list | array | 订单列表 |
| data.list[].id | number | 订单ID |
| data.list[].orderNo | string | 订单编号 |
| data.list[].orderPrice | number | 订单价格 |
| data.list[].orderNum | number | 订单数量 |
| data.list[].userId | number | 用户ID |
| data.list[].createDate | string | 创建时间 |
| data.list[].payDate | string | 支付时间 |
| data.list[].callbackDate | string | 回调时间 |
| data.list[].payChannel | string | 支付渠道 |
| data.list[].channelId | number | 景区ID |

**请求方法**：POST

**请求参数**：
| 参数名 | 类型 | 必填 | 描述 |
| --- | --- | --- | --- |
| userName | string | 是 | 用户名 |
| password | string | 是 | 密码 |
| deviceId | string | 否 | 设备ID |

**响应参数**：
| 参数名 | 类型 | 描述 |
| --- | --- | --- |

| data.userInfo | object | 管理员信息 |
| data.userInfo.id | number | 管理员ID |
| data.userInfo.username | string | 用户名 |
